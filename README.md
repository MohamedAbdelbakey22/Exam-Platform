# 🎓 Exam Platform with AI Monitoring

A comprehensive and secure **Online Examination System** built with **Angular**. This platform is designed to streamline the testing process while maintaining high integrity through automated proctoring.

## 🧠 AI-Powered Proctoring (Key Feature)
The standout feature of this platform is the **AI Identity Verification Module**:
* **Continuous Monitoring:** Uses the laptop camera to ensure the student's presence throughout the exam.
* **Identity Check:** Real-time facial verification to ensure the person taking the exam is the authorized student.
* **Anti-Cheating:** Detects unauthorized behavior to maintain academic integrity.

## ✨ Features
* **Student Dashboard:** View upcoming exams, results, and performance analytics.
* **Interactive Exams:** Responsive UI for answering questions with a countdown timer.
* **Result Analysis:** Automatic grading and instant feedback for students.
* **Secure Login:** Role-based access for students and instructors.

## 🚀 Technologies Used
* **Frontend:** Angular Framework.
* **Styling:** Bootstrap 5 & CSS3 for a modern and responsive user interface.
* **Logic:** TypeScript & JavaScript (ES6+).
* **AI Integration:** Specialized AI monitoring module for identity verification.
* **Tools:** Git & GitHub for version control.
